# 复习系统

基于艾宾浩斯遗忘曲线和海马体记忆巩固原理，进行科学间隔复习。

## 启动步骤

1. 读取 `~/.claude/user-memory/learning/overview.md`（学科状态总览）
2. 读取各学科文件，识别需要复习的内容
3. 展示今日复习建议，询问：**要复习哪个？** 或 **全部过一遍**

## 复习时机判定

使用简化版 SM-2 算法（SuperMemo 2），根据上次复习效果计算下次间隔：

| 回忆效果 | 下次间隔倍数 | 说明 |
|----------|--------------|------|
| 完全回忆，轻松 | ×2.5 | 记忆稳固，拉长间隔 |
| 回忆起来但费力 | ×1.5 | 需要加强，适度延长 |
| 模糊/部分回忆 | ×1.0 | 保持当前间隔 |
| 完全想不起 | →1天 | 重置，次日重试 |

默认序列：1天 → 3天 → 7天 → 14天 → 30天 → 60天 → 120天...

**判定逻辑**：
- 学科文件中"笔记"段记录的内容为复习素材
- 每条笔记记录 `(上次复习日期, 间隔, 质量评分)`
- 超过间隔的内容进入今日复习列表

## 复习流程

当用户选择复习内容后：

1. **提示回忆**：只给提示，不给答案（"回顾一下 Lean 4 的 Sigma 类型，它和 Pair 有什么区别？"）
2. **等待回答**：用户用自己的话复述，不要求精确，重点在思维过程
3. **补充连接**：根据回答补充关键点，并**关联其他学科**（如：关联 Lean 4 的依赖类型到 Agent 的形式化验证需求）
4. **评估效果**：询问"这次回顾感觉怎样？"，记录效果评分
5. **更新记录**：在学科文件末尾的"复习记录"段追加/更新对应条目，计算下次复习日期

## 复习记录格式

在学科文件末尾新增独立的**复习记录**段（不与笔记混在一起）：

```markdown
## 复习记录

| 知识点 | 上次复习 | 间隔 | 效果 | 下次复习 |
|--------|----------|------|------|----------|
| Sigma 类型 | 03-25 | 1天 | 4 | 03-26 |
| ...
```

**效果评分**：1-5（1=完全想不起，5=轻松回忆）

## 对话式复习（轻量模式）

用户说"快速复习"时进入：

1. 从今日复习列表选 3-5 个关键概念
2. 串起来提出一个问题（"回顾一下：闭包、Lean 4 的作用域、Agent 的状态管理，三者在'边界'这个概念上有什么共通点？"）
3. 引导跨域连接，激活 Ne 优势
4. 不逐条评分，整体印象记录

**优势**：降低心理负担，利用 Ne 的跨域连接能力

## 会话结束

1. 更新所有复习过的笔记记录
2. 更新 `learning/overview.md`：记录今日复习了哪些学科
3. Git 提交：
   ```
   cd ~/.claude/user-memory
   git add learning/
   git commit -m "复习更新：[学科名]"
   ```

## 复习原则

- **提取优先**：先让用户回忆，再补充。被动重看效果差
- **跨域连接**：复习时主动关联其他学科，双重编码巩固记忆
- **效果诚实**：用户说"模糊"就记模糊，不自欺
- **负担可控**：单次复习不超过 15 分钟，可分多次
- **不强求**：用户不想复习就不推，宁缺毋滥

## 与 assistant-learn 的关系

- `assistant-learn`：学习新知识，推进路线图
- `assistant-review`：巩固已学知识，对抗遗忘
- 两者互补：学完必复习，复习时发现薄弱点可回炉学习
