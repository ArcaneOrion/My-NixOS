# 复习系统

基于艾宾浩斯遗忘曲线和海马体记忆巩固原理，进行科学间隔复习。

**核心设计**：巩固是底层机制，重联是表层体验。SM-2 调度间隔不变，但每次复习的任务不是"回忆 X 是什么"，而是"用 X 去连接 Y"。提取旧知识的动作隐式发生在跨域连接的过程中——用户主观体验到的是"发现新关系"，海马体实际执行的是"提取并重新编码"。

## 启动步骤

1. 读取 `~/.claude/user-memory/learning/overview.md`（学科状态总览）
2. 读取各学科文件，识别需要复习的内容
3. 展示今日复习建议，询问：**要复习哪个？** 或 **全部过一遍**

## 复习时机判定

使用简化版 SM-2 算法（SuperMemo 2），根据上次复习效果计算下次间隔：

| 回忆效果 | 下次间隔倍数 | 说明 |
|----------|--------------|------|
| 完全回忆，轻松 | ×2.5 | 记忆稳固，拉长间隔 |
| 回忆起来但费力 | ×1.5 | 需要加强，适度延长 |
| 模糊/部分回忆 | ×1.0 | 保持当前间隔 |
| 完全想不起 | →1天 | 重置，次日重试 |

默认序列：1天 → 3天 → 7天 → 14天 → 30天 → 60天 → 120天...

**判定逻辑**：
- 学科文件中"笔记"段记录的内容为复习素材
- 每条笔记记录 `(上次复习日期, 间隔, 质量评分)`
- 超过间隔的内容进入今日复习列表

## 复习流程（知识重联模式）

当用户选择复习内容后：

1. **构造跨域问题**：不问"X 是什么"，而是构造一个需要用旧知识 X 去连接新领域 Y 的问题。连接素材来源：
   - 用户最近学的其他学科的新知识点
   - 用户最近在 journal 或 raw/ 中讨论的新想法
   - 不同学科之间的结构性类比
   - 例：复习 Lean 4 依赖类型时，不问"依赖类型的定义"，而问"依赖类型的'值决定类型'和你的自体实验框架中'生物状态决定意识清晰度'有没有结构上的相似性？"
2. **等待回答**：用户用自己的话分析，重点在思维过程和连接质量
3. **补充深化**：根据回答补充关键点，指出用户可能没注意到的更深层连接
4. **评估效果**：同时评估两个维度——旧知识的提取质量 + 跨域连接的深度
5. **更新记录**：在学科文件末尾的"复习记录"段追加/更新对应条目，计算下次复习日期

## 复习记录格式

在学科文件末尾新增独立的**复习记录**段（不与笔记混在一起）：

```markdown
## 复习记录

| 知识点 | 上次复习 | 间隔 | 效果 | 连接到 | 下次复习 |
|--------|----------|------|------|--------|----------|
| Sigma 类型 | 03-25 | 1天 | 4 | Agent graceful degradation | 03-26 |
| ...
```

**效果评分**：1-5（1=完全想不起，5=轻松回忆且产生新洞察）

## 对话式复习（轻量模式）

用户说"快速复习"时进入：

1. 从今日复习列表选 3-5 个关键概念
2. 串起来提出一个问题（"回顾一下：闭包、Lean 4 的作用域、Agent 的状态管理，三者在'边界'这个概念上有什么共通点？"）
3. 引导跨域连接，激活 Ne 优势
4. 不逐条评分，整体印象记录

**优势**：降低心理负担，利用 Ne 的跨域连接能力

## 会话结束

1. 更新所有复习过的笔记记录
2. 更新 `learning/overview.md`：记录今日复习了哪些学科
3. Git 提交：
   ```
   cd ~/.claude/user-memory
   git add learning/
   git commit -m "复习更新：[学科名]"
   ```

## 复习原则

- **重联优先**：每次复习必须产生新连接，纯重复回忆是底线而非目标
- **提取优先**：先让用户回忆和连接，再补充。被动重看效果差
- **跨域连接**：复习时主动关联其他学科，双重编码巩固记忆
- **效果诚实**：用户说"模糊"就记模糊，不自欺
- **负担可控**：单次复习不超过 15 分钟，可分多次
- **不强求**：用户不想复习就不推，宁缺毋滥

## 与 assistant-learn 的关系

- `assistant-learn`：学习新知识，推进路线图
- `assistant-review`：巩固已学知识 + 发现跨域连接，对抗遗忘的同时产生新理解
- 两者互补：学完必复习，复习时发现薄弱点可回炉学习，复习中产生的新洞察可反哺学习方向
